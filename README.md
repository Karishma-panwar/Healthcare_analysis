# 🏥 Healthcare Analysis Dashboard

## 📌 Project Overview

This project analyzes healthcare data to understand **patient trends, hospital performance, doctor workload, treatment costs, and revenue patterns**.

An interactive dashboard was developed to transform raw healthcare data into meaningful insights and support **data-driven decision-making in healthcare management**.

## 🎯 Objectives

* Analyze patient demographics and visit trends
* Identify the most common diagnosis and reasons for visits
* Evaluate hospital performance and revenue generation
* Analyze doctor workload and department performance
* Monitor treatment costs and healthcare expenses
* Analyze follow-up and patient visit patterns
* Identify key trends to support better resource planning

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **Excel** – Data preparation and analysis
* **SQL** – Data querying and data analysis
* **DAX** – KPI calculations and measures

## 📊 Key KPIs

* Total Patients
* Total Revenue
* Average Patient Age
* Follow-up Rate
* Doctor Workload
* Average Treatment Cost
* Top Diagnoses
* Top Revenue-Generating Hospitals

## 📈 Dashboard Sections

### 1. Healthcare Overview

Provides an overall view of healthcare operations, including patient volume, visits, diagnoses, revenue, and key trends.

### 2. Hospital Insights

Analyzes hospital performance using revenue, patient visits, department performance, and doctor workload.

### 3. Patient Insights

Provides detailed analysis of patient demographics, visit types, reasons for visits, diagnoses, treatments, and costs.

## 🔍 Key Insights

* **Emergency cases and flu symptoms account for a significant share of patient visits**, highlighting the need for effective emergency and seasonal-care resource planning.
* Identified the **top revenue-generating hospitals** based on healthcare charges.
* Analyzed **doctor workload across departments** to understand resource utilization.
* Evaluated **treatment costs and average cost per visit** across different healthcare services.
* Analyzed patient demographics and visit patterns to identify important healthcare trends.
